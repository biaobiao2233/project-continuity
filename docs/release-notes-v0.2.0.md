# Project Continuity v0.2.0

## Highlights

This release consolidates the latest Project Workbench improvements and makes the operating principles available as reusable open-source guidance.

## Added

- Proportional governance model (L0-L3)
- GitHub-first project tracking guidance
- Scope and ownership boundaries
- Session continuity and handoff principles
- Acceptance state separation
- Runtime-agnostic integration guidance
- Public custom instruction templates

## Design direction

Project Continuity is intended to help AI agents work reliably across sessions and tools without forcing unnecessary process overhead.
