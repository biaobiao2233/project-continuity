# Historical Memory Routing

Historical/semantic memory is useful for discovery and source location, not as the authoritative current project ledger or live-state monitor.

Do not use derived memory alone to prove current machine/repo state, exact user authorization, final PASS, exact wording when source exists, production version, Session Pin, or write ownership.

Typical sequence:
`Handoff / Active Work Node → canonical Issue/PR/source pointers → relevant accepted predecessor → historical search only if context is still missing → exact source when needed → current repo/live verification`

Runtime-specific memory connector names and commands belong in that agent's global guidance, not in this Skill.
