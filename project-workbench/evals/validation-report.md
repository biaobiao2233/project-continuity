README 使用稳定入口或带时间/来源的派生视图，避免和 worklog 各自维护一份“当前真相”。不新增后台调度器、守护进程、自动抢占或公共隧道。

## 检查器的能力边界

`resume / preflight / deliver / integrate` 读取调用方提供的 JSON 快照，只检查声明之间的结构一致性、资源冲突及版本/证据缺口。脚本不联网、不执行快照中的命令、不写项目文件、不创建分支、不合并、不部署、不发放权限，也不实施真实互斥锁。

证据引用只作格式与存在性检查，不会读取和认证其内容。调用者必须先通过实际工具取得当前信息；别名、符号链接、遗漏的检查和未列出的写入者不能由这个快照检查器自动发现。`CHECKS_CLEAR` 不是项目 PASS、权限授予或独立审查。
